Themis: Armenian legal assistant

A legal chat app that answers questions in Armenian, Russian and English, refuses anything off-topic, and recommends which lawyer to consult based on similar past cases.

  • Fine-tuned Qwen2.5-7B (ArmChat, GGUF Q4_K_M) served locally through Ollama; bge-m3 embeddings for retrieval over the ARLIS legal Codes and DataLex court cases.
  • CrewAI agent writes the answer; any sentence that cites an article missing from the retrieved sources is removed, and Armenian answers quote the sources directly.
  • Input checks for gibberish and prompt injection, Whisper voice input, guest mode or saved history with JWT accounts for individuals and lawyers.
  • Written data, privacy and retention policy, backed by tests.

Research · health NLP · data engineering

Ozempic drug-experience chatbot research

Research toward a chatbot that answers questions about GLP-1 drugs like Ozempic using what patients actually report. My part was the data layer: an automated pipeline that collects and normalises Reddit discussions for analysis and labeling.

daily cron→Arctic Shift API→raw JSONL.gz→schema v1.0→curated JSONL→labeling
  • GitHub Actions job collects posts and comments from GLP-1 subreddits every day, using checkpoints so each run resumes where the last one stopped.
  • Each day is collected only after 72 hours, once scores and comment counts have settled. Re-runs overwrite the same files, so there are no duplicates or gaps.
  • Raw and curated layers with JSON Schemas, a Parquet option and S3-ready output. The data is mirrored to the team's repositories.
